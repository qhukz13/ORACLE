# 2026-08-24 — P6-T4: the reference scenario stops being a diagram

Requirements 1–4 and 6 of [P6-T4](../../docs/current_task.md). The phase's twelve-step scenario in
[INTEGRATIONS.md §8](../../docs/INTEGRATIONS.md#8-reference-scenario) is now a test that runs in CI,
offline, every time. Gate green.

## Two places the design sketch was wrong, and building it said so

**Step 7 needs no model.** The sketch had the router deciding to escalate. In practice the signal is
"a verification tool reported failure in this turn" — a fact about `dev.run_tests`, not a judgement —
and a model deciding to spend money on a stronger model is a loop nobody asked for. Deterministic is
cheaper *and* more reliable here. Kept narrow on purpose: a suite that ran and failed escalates, a
tool that could not run (denied, runner missing, bad path) does not, because a delegate would hit
exactly the same wall and bill for the privilege.

**Step 9 is the only prompt.** An earlier reading had ORACLE ask "shall I delegate?" and then "here
is what would be sent" — two questions for one decision, which is the prompt fatigue
[SECURITY.md §2](../../docs/SECURITY.md#2-design-principles) exists to avoid. Escalation *starts* the
delegation; the egress preview is where a human says no, and a refused delegation costs a packet
render and nothing else.

## A stub that had outlived its phase

"ask Claude to …" never reached the classifier at all: the **pre-router** has recognised it
deterministically since P1 and was answering *"Delegation arrives in Phase 6 — for now I can only
route it."* It arrived. The explicit route now costs ~5 ms and no model call, which is the pre-router
doing exactly what [OQ-15](../../docs/OPEN_QUESTIONS.md#oq-15) wanted more turns to do.

A project the user named in their own sentence is used; anything else **asks**. That asymmetry is
deliberate: a wrong answer costs a retry, and a delegation against the wrong repository sends that
repository's context to a cloud API.

## The test, and what it is for

`tests/test_reference_scenario.py` drives the real pipeline, gate, approval store, packet renderer,
worktree and collection; only the local model and the vendor CLI are replays. What it asserts is the
**order** — tool call before approval request, approval before any egress, collection before report —
because the order is the design and everything else is detail. A `SpyAdapter` counting `submit()`
carries the load-bearing assertion: nothing egressed before the human was asked.

Its sibling case earned its keep immediately: green tests must not escalate, and the first version
of the harness hardcoded `ok=False`, so it escalated on a passing run. The test caught my fixture,
which is the correct thing for a test to catch.

## Also

The command palette offers a delegation once the query names a known project, worded so the entry
says a human still approves what is sent — the palette item is half a decision whose other half is
the preview. `delegating` is documented in AGENT_RUNTIME.md as a *handoff*, not a wait: the turn
finishes `delegated` and the delegation streams on under `task.*`, because a session blocked for ten
minutes on work the user can already watch in the panel is a worse UI than no delegation at all.
